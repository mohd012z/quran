# Al-Fatihah opening presentation policy

User preference: Basmalah as separate opening; Alhamdulillah as first numbered reading line.

This is a presentation preference, not permission to modify canonical Tanzil text or source numbering.

Canonical 1:1 is Basmalah in the existing Tanzil edition; canonical 1:2 starts Alhamdulillah. Display line 1 may map to canonical 1:2, but must not be called a verified alternative canonical ayah 1.

Keep canonical surah and ayah IDs, Arabic, audio, translation, bookmark and share references unchanged.

An alternative seven-verse scheme requires independently verified terminal verse segmentation; do not invent boundaries.

No Basmalah opener for At-Tawbah; preserve Basmalah within An-Naml 27:30.

Do not change Quran text or enable an alternative numbering scheme until verified against an authoritative mushaf edition.

Regression gates: Al-Fatihah, Al-Baqarah, At-Tawbah, An-Naml, audio, Tajweed, translations, bookmarks, share links, offline reading.

Research branch only; no deployment or billing.
